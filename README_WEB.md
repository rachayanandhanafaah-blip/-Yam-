# Yam7 เว็บแอป (GitHub Pages)

## ติดตั้งครั้งแรก
1. สร้าง/เปิดรีโป (เช่น `-Yam-`) → อัปโหลด **ทุกไฟล์ในแพคนี้** ไว้ที่ราก (root) ของรีโป รวมโฟลเดอร์ `tools/` และไฟล์ `.nojekyll`
   - ไอคอนในแพคเป็นชุดที่ผู้ใช้กำหนด **ใช้ชุดนี้เสมอ** (`icon-192.png` ย่อมาจาก `icon-512.png`) ห้ามสร้างไอคอนใหม่ทับเมื่ออัปเดต
   - ถ้ามี `build.js` เดิม ลบทิ้งได้ (รุ่นนี้สร้างรหัสรุ่นเองจากตัวไฟล์)
2. Settings → Pages → Deploy from a branch → `main` / `(root)`
3. เปิด `https://<user>.github.io/<repo>/` → เมนู ⚙️ → ติดตั้งเป็นแอป

## อัปเดตรุ่นใหม่ (ทุกครั้ง)
**แทนที่ไฟล์ `yam7.js` ไฟล์เดียว** (Add file → Upload files → ลากไฟล์ `yam7.js` ทับ → Commit)
- ไม่ต้องแก้ `build.js` `sw.js` `index.html` หรือไฟล์อื่น
- หน้าเว็บโหลด `yam7.js` ใหม่ทุกครั้งที่เปิดตอนออนไลน์ · ถ้ามีคนเปิดค้างไว้จะขึ้นแถบ "มีรุ่นใหม่ของแอป → อัปเดต" ภายในไม่กี่วินาทีหลัง GitHub Pages deploy เสร็จ (ปกติ ๑–๒ นาที)
- ออฟไลน์ใช้สำเนาล่าสุดที่เคยโหลด
- ไฟล์ `yam7.js` ต้องเป็นไฟล์เดียวกับที่ใช้ใน Scriptable (มีบรรทัด `const PARAM` อยู่ท้ายส่วนฟังก์ชัน — ตัวโหลดตัดที่บรรทัดนี้ ห้ามลบ/เปลี่ยนชื่อ)

## ไฟล์
| ไฟล์ | หน้าที่ | แก้เมื่ออัปเดต? |
|---|---|---|
| `yam7.js` | ตัวแอป (ร่วมกับ Scriptable) | **ใช่ — ไฟล์เดียวที่ต้องแทนที่** |
| `index.html` | หน้าหลัก | ไม่ |
| `loader.js` | โหลด yam7.js ตัดทางเข้า Scriptable ตั้งรหัสรุ่น `Y7_BUILD` = รุ่น-แฮช | ไม่ |
| `shim.js` | จำลอง API ของ Scriptable ในเบราว์เซอร์ | ไม่ (ยกเว้นแอปเรียก API ใหม่) |
| `app.js` | ตัวควบคุมหน้า: ลิงก์ `yam://` เมนู ติดตั้ง ตรวจรุ่นใหม่ | ไม่ (ยกเว้นเพิ่มลิงก์ `yam://…` ใหม่ในแอป) |
| `sw.js` | ออฟไลน์ (ดึงไฟล์ใหม่ก่อนเสมอ) | ไม่ |
| `manifest.webmanifest` + ไอคอน | ติดตั้งเป็นแอป | ไม่ |
| `tools/host_test.js` | ทดสอบก่อนอัปโหลด | — |

## ทดสอบก่อนอัปโหลด (ไม่บังคับ)
```
node tools/host_test.js yam7.js
```
ต้องขึ้น `✅ host_test ผ่านทั้งหมด` (จำลองเบราว์เซอร์: โหลดไฟล์ · ๔ แท็บ · บันทึกดวง · ลิงก์ yam:// · โหมดสี · ตรวจรุ่นใหม่)

## ถ้าเปิดแล้วขึ้น "เกิดข้อผิดพลาด"
- `yam7.js HTTP 404` → ไฟล์ไม่อยู่ที่ราก หรือ Pages ยัง deploy ไม่เสร็จ
- `ไม่พบ computeAll` → `yam7.js` มี syntax error หรือไม่ครบ (อัปโหลดขาด) ให้อัปใหม่
- ค้างรุ่นเก่า → ปิดแอปเปิดใหม่ ๒ ครั้ง หรือ Settings เบราว์เซอร์ → ล้างข้อมูลเว็บไซต์
- ข้อมูลตั้งค่า/ประวัติเก็บในเบราว์เซอร์เครื่องนั้น (localStorage) ไม่หายเมื่ออัปเดต
